## Task Instructions

Generate **12,000 unique interview questions** following these rules:

### 1. Mandatory uniqueness
- **ALL questions must be 100% unique in their `questionContent`.**  
- **No two questions can have the same content**, even if they belong to different topics, levels, or types.  
- Ensure content variety using realistic IT interview phrasing, examples, and context.  
- Avoid placeholders like "Sample question"; generate meaningful, distinct questions.

### 2. Question structure
Each question must have:
- `fieldId` → existing in DB
- `topicId` → must belong to the correct `fieldId`
- `levelId` → existing level
- `questionTypeId` → existing type

Every combination of **field × topic × level × questionType** must have **at least 10 unique questions**.

### 3. Question type guidance

id | Question Type         | Template Example                                                                 |
---|-----------------------|---------------------------------------------------------------------------------|
1  | Single Choice         | "Which of the following is true about [topic]?" Answer: "Option A is correct."  |
2  | Multiple Choice       | "Select all correct statements about [topic]." Answer: "Options A, C, D are correct." |
3  | Fill in the Blank      | "Explain how [topic] works in [context]." Answer: "Your detailed explanation." |
